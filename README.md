# Bike Shop — Landing Page

> A responsive, pixel-polished landing page for a fictional bike shop — built entirely with **HTML5** and **CSS3**, no frameworks, no JavaScript.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)
![Status](https://img.shields.io/badge/status-complete-success)

---

## About the Project

A static landing page designed from scratch to practice core front-end skills — semantic HTML structure, CSS layout techniques (Flexbox, Grid), responsive design, and visual polish — without relying on any framework or library.

The goal was to build something that looks professional using only the fundamentals.

---

## Features

- **Fully responsive** — adapts cleanly from mobile to desktop
- **Semantic HTML** — accessible, well-structured markup
- **Custom CSS** — Flexbox/Grid layouts, hover effects, and transitions
- **No dependencies** — zero JavaScript, zero frameworks, just HTML and CSS

---

## Project Structure

```
Bike-Shop/
├── assets/       # Images, icons, and other media
├── index.html    # Main HTML page
└── style.css     # All styling
```

---

## Getting Started

No build step needed — just open it in a browser:

```bash
git clone https://github.com/Mohamed-G-Omer/Bike-Shop.git
cd Bike-Shop
open index.html
```

Or simply double-click `index.html` on your computer.
